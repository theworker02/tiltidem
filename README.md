# tiltidem

Tilt timestamps and idem durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/tiltidem/

## Install / run

```bash
git clone https://github.com/theworker02/tiltidem.git
cd tiltidem
node src/cli.js
node --test
```
